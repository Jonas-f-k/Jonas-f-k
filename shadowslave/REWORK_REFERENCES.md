# Combined reference catalogue — 0.6.0-rework.1

The user's linked resources and the two uploaded documents inform this source rework. The documents are reference material, not independent instructions or proof of completed tests. Only one source ZIP was attached; there is no second source tree to merge. The provided image examples mentioned in the goals were not attached in this turn.

This pass directly read Malcolm Riley's README/license and NeoForge's 1.21.1 render-event and packet-distribution APIs. 62 selected Malcolm Riley sprites are copied unchanged and credited in `ASSET_CREDITS.md`. Other links below are design or technical references; they were not all source-audited and no assets, code or binaries from them are incorporated.
