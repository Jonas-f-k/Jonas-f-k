# Terrain and vegetation presentation

Natural ground uses subtle stone, dirt and grass clusters. Gold symbols are reserved for crafted magical materials. Grass has a ragged cap over soil; tree trunks have bark sides and separate cut ends. Foliage keeps a transparent Minecraft leaf pattern.

Shipped living-tree configured features now call the registered native tree feature. Broadleaf trees vary height, lean, branch count, crown radius and off-center crown lobes. Conifers use staggered unequal boughs and air gaps. Grove/moonlit trees may have a few hanging tips. Placement preserves supported ground and rejects an obstructed trunk. Existing flowers are generated separately.

Bright end-rod biome particles are replaced with much rarer small ash motes. Petals and spores are also less frequent. These changes are generated by `tools/build_worldgen.py`, so rebuilding data preserves them.

Textures update in existing chunks. Tree geometry and particle biome settings are evaluated most reliably in newly generated chunks or a new test world; already placed trees retain their existing block shapes.
